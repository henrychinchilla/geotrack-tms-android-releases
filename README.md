# GeoTrack TMS - Releases Android

Este repositorio publica únicamente los APK firmados de la app Android de GeoTrack TMS.

## Instalación
1. Descargue `geotrack-tms.apk` desde la última versión en [Releases](../../releases/latest).
2. En el teléfono, permita instalar aplicaciones de esta fuente cuando Android lo pida.
3. Abra la app e inicie sesión; otorgue el permiso de ubicación «Permitir todo el tiempo» para el rastreo.

Las actualizaciones se instalan sobre la versión anterior sin desinstalar (misma firma).

## Código fuente
El código fuente de GeoTrack TMS es privado; aquí solo se distribuyen los binarios.
